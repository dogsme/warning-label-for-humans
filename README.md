## The label

> WARNING: This human runs on three hours of sleep, one cup of coffee, and the firm belief that the rules are for other people.

One line, 125 characters, printed on every human being — because the warning only works if everyone recognises themselves in it.

## How it works

`main.py` (Python 3.13) writes that single line to `/output/entry.txt` as UTF-8 text.

```sh
python3 main.py
cat /output/entry.txt
```
